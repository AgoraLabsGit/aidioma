# /research

Create `Docs/Research/R-nnn.md` from `Docs/Development/Templates/research.md`. Compare only the
options needed for the named decision, state the verdict and revisit condition, link affected specs
and phase, and append any resulting choice to `Docs/DECISIONS.md`. Log follow-up implementation in
`Docs/WORK.yaml`. Run `npm run docs:check`.
