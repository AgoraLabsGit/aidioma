# Release entry

Append one entry to `Docs/RELEASES.md` after a verified production release.

```markdown
## RELEASE-nnn — Short learner-visible summary
Date: YYYY-MM-DD
Phase: PHASE-nnn
Receipt: refs/aidioma/close-receipts/...
Deployment: <production deployment ID or URL>
```

One entry represents one production ship. Link the matching publication evidence; never claim a
release from a local candidate alone.
