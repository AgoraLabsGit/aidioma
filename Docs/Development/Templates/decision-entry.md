# Decision entry

Append one choice to `Docs/DECISIONS.md`; do not rewrite an old choice to hide history.

```markdown
## D-000 — Subject: choice
Date: YYYY-MM-DD · Phase: PHASE-000 · From: R-000 · Affects: [SPEC-F-NAME]
Chose: selected option over alternatives
Why: the reason that decided it
Revisit if: a concrete condition
```

Use `Supersedes: D-000` in a new entry when a prior decision changes.
