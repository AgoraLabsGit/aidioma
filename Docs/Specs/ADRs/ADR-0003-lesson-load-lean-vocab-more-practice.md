# ADR-0003 — Lesson load: lean vocab, more practice

## Decision
Authoring guideline for launch lessons (schema ceilings unchanged):

| Field | Aim | Schema band (unchanged) |
|---|---|---|
| New vocab / lesson | **12–15** | 8–15 |
| Practice sentences / lesson | **18–20** | 12–20 |

Comprehension comes from **more reps** (sentences + MC + story + blend), not from 25–50 new words per lesson.

## Why
Operator rejected “aim 10” as too thin for practice feel; clarified that the fix is denser practice inside existing bands, not fatter vocab dumps (which hurt retention and QA).

## Consequences
- C2 drafts target the top of each band.
- No schema proposal. A future request for fat vocab (25+) needs a new feature decision; it is not parked launch scope.
- Style guide should mirror this aim when content lane un-pauses.

## Closes
OI-005.
