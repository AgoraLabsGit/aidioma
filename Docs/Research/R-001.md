# Downloadable Spanish dictionary for AIdioma

## Question

AIdioma needs a **machine-readable Spanish dictionary** we can legally download and use for
Lexicon (Spanish-first entry+sense). Choice is not “any word list” — it must have **senses**, a
clear license for a commercial learner app, and a format we can filter/import. Frequency lists
already covered separately (`content/curriculum/research/frequency-vocab.md`).

## Options

| Option | Strengths | Costs | Notes |
|---|---|---|---|
| A. Kaikki / Wiktextract **eswiktionary** | Structured JSONL; Spanish glosses; ~95MB `.gz`; weekly dumps; POS/senses | **CC-BY-SA + GFDL** (share-alike if redistributed); noisy wiki quality | Best Spanish-first dump: https://kaikki.org/eswiktionary/rawdata.html |
| B. Kaikki **enwiktionary → Spanish** | ~769k forms; **English** glosses; same extractor | Full EN dump huge (filter `lang_code=es`); same CC-BY-SA | Better if help text must be English: https://kaikki.org/dictionary/Spanish/ |
| C. FreeDict eng↔spa | Ready bilingual packs (e.g. eng→spa ~64k); TEI/slob downloads | Mostly **GPL**; spa→eng thin (~4.5k); glosses shallow | https://freedict.org/downloads/ |
| D. MCR / Spanish WordNet | **CC-BY 3.0**; synsets + relations | Not a learner dictionary (no traditional defs) | Good for NLP links, not UI sense text |
| E. FreeLing `es` morphology | Large form↔lemma table | **LGPLLR**; no definitions | Lemmatizer only |
| F. RAE / unofficial RAE APIs / scraped corpora | Gold monolingual quality | **Not redistributable**; scrape/API ≠ download license | Reject for shipping or bundling |

## Verdict

**Use A — Kaikki Wiktextract from Spanish Wiktionary** as the downloadable dictionary source.

1. Only option that is both **downloadable structured senses** and **Spanish-first**.
2. License is open (credit + share-alike on redistributed dictionary data) — workable if we ship a
   **curated extract** under content pipelines, not a silent full dump.
3. Pair with **B** only when a sense needs an English gloss; keep frequency checks on wordfreq
   (existing curriculum research).

**Reject F** for any shipped or redistributed Lexicon data. **Defer C/D/E** — wrong shape or
heavier license for little Lexicon gain.

## Revisit if

- Legal review blocks CC-BY-SA inside the commercial app (then: author-only consult, no ship; or
  CC-BY WordNet for relations only).
- Product requires official RAE-grade monolingual prose (needs a paid/licensed corpus, not a free dump).
- We need offline EN glosses at scale and filtering enwiktionary becomes cheaper than maintaining B
  extracts.
