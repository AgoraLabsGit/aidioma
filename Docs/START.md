# Welcome to AIdioma

Learner product work lives in this repo. Start with local `Docs/NOW.md` when present, then
`Docs/WORK.yaml`, `Docs/PRODUCT.md`, and the active roadmap phase under `Docs/Roadmap/Phases/`.
A phase `/run` agent coordinates and delegates coding by area; it does not implement the phase
itself.

Use `Docs/COMMANDS-OVERVIEW.md` for native commands and `Docs/Development/` for templates. Run `npm
run docs:check` after metadata changes. Before `/close` or `/phase-close`, read `Docs/CLOSE.md`;
close uses candidate-pinned deterministic proof and independent multi-agent audits.
